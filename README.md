# Video Editing Toolkit — Motion Graphics & Asset Suite

The open-source, copyright-free asset vault for video editors, motion designers, and content creators. Contains **6,200+ production-ready assets** compatible with Adobe Premiere Pro, After Effects, DaVinci Resolve, CapCut, and Final Cut Pro.

## Directory Structure

```
.
├── audio/
│   ├── sound-effects/    # 320 lossless WAV sound effects (whooshes, risers, booms, impacts, UI, etc.)
│   ├── background-music/ # Background music tracks (.mp3)
│   └── ambience/         # Atmospheric audio beds
├── b-roll/
│   ├── lifestyle/        # Video clips (.mp4) and photographic cutouts
│   ├── nature/           # Nature environments
│   ├── city/             # Urban footage
│   └── technology/       # Tech clips
├── captions/             # Subtitle & caption templates (.srt, .vtt)
├── editing-templates/    # NLE project templates (Premiere Pro, AE, Resolve, CapCut)
├── icons/
│   ├── svg/
│   │   ├── brands/       # 3,400+ SVG brand and platform logos (CC0)
│   │   └── ui/           # 2,000+ SVG UI, editing tool, media controls, and symbols (ISC/MIT)
│   ├── png/              # High-resolution raster icons & logos
│   └── animated/         # Looping animated GIF reactions
├── luts/                 # 3D cinematic LUTs (.cube) with visual previews
├── motion-graphics/      # 3D icon collages and abstract scenes
├── overlays/             # Light rays bursts, page curls, atmospheric textures
├── png-assets/
│   ├── cutouts/          # Classical statues (01-36), body parts, gestures, people silhouettes
│   ├── stickers/         # Badges, shapes, sparkles, fire frames, lightning, particles
│   └── objects/          # Clocks, compasses, money, cards, chess, crypto, devices, masks
├── previews/             # Project and asset showcase previews (.mp4)
├── titles-and-text/      # Text overlays and typography cutouts
├── transitions/          # Alpha/Luma matte transition SVGs (wipes, iris, slashes)
├── ui-assets/            # Dark mode UI buttons, video player frames
├── vectors/
│   ├── illustrations/    # 3D & 2D scene/character illustrations (illustration_*.png)
│   ├── arrows/           # Directional pointers and visual flow arrows (arrow_*.png)
│   └── infographics/     # Market charts, coin growth, productivity graphs (chart_*.png)
├── LICENSE               # Open-source and CC0 terms
├── ASSET-LICENSES.csv    # Per-file license registry (6,200+ entries)
├── PNG_INDEX.md          # 318 PNG assets with dimensions & keyword descriptions
└── README.md
```
